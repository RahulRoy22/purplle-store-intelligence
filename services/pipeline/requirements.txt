# PyTorch index

# Uncomment exactly ONE --extra-index-url block below to match your hardware.
# The CPU block is active by default (safe for any machine; ~750 MB download).
# Switch to a CUDA block if you have an NVIDIA GPU — inference will be 5-10×
# faster.  Do NOT have two --extra-index-url lines active at the same time.
#
#   CPU-only (default — works on all machines):
--extra-index-url https://download.pytorch.org/whl/cpu
#
#   CUDA 11.8  (GTX 10xx / RTX 20xx / 30xx, driver ≥ 452):
# --extra-index-url https://download.pytorch.org/whl/cu118
#
#   CUDA 12.1  (RTX 40xx, driver ≥ 530):
# --extra-index-url https://download.pytorch.org/whl/cu121
